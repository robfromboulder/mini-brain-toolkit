# Distribution: Burndown

Everything between working code and a merged PR.

## Routine

* commit and push the finished change on the work branch
* create draft PR
* review code changes
* full rebuild and automated retest on PR code
* review PR description against final code one last time
* request feedback from reviewers
* respond to review feedback
* automated checks — see `MBT_DISTRIBUTION_CLAUDE.md`
* manual checks — capture steps in `MBT_DISTRIBUTION_TESTING.md`
* closeout notes — <deviations from the standard flow, and any canonical claim this work item reverses — see `templates/WORK_CLOSEOUT.md`>

## Custom

* docs — README install block per channel that lands
* tag a release carrying the packaging before any submission
* GitHub repo topics
* submit to Anthropic's plugin directory
* submit to the OpenAI plugin directory, if a skill-only plugin qualifies
* submit to hesreallyhim/awesome-claude-code through the web issue form (Rob)
* submit to travisvn/awesome-claude-skills at 10 stars, PR written by Rob
* reply to Agensi

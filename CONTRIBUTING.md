# Contributing to mini-brain-toolkit

This project requires [Claude Code](https://claude.ai/code) for all development. See `CLAUDE.md` for project-specific instructions.

## Development Workflow

Open Claude Code at the repo root — `CLAUDE.md` loads automatically, and its read index tells Claude which files to read for each question.

At each natural stopping point, ask Claude to update the session log. Decisions that aren't captured in the log are lost to future sessions.

Submit changes as pull requests, reviewable like any other code.
